# Regression cases.  Each case runs a CMake-built executable and compares its
# stdout+stderr byte-for-byte with golden/<name>.out.
#
#   name | target | stdin file | arguments | check
#
# target     executable built by CMakeLists.txt (or tests/CMakeLists.txt)
# stdin      resolved in regress/fixtures/ first, then the source root;
#            empty means /dev/null
# check      empty for an exact diff against golden/<name>.out, or "sha256"
#            for outputs too large to store: golden/<name>.sha256 then holds
#            the digest and line count
#
# All programs use fixed seeds.  Builds use -ffp-contract=off, so results do
# not depend on the optimization level.  Golden files were produced on macOS
# arm64 with Apple clang and libm; another libm may differ in the last digits.
