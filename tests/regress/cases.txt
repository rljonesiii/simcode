# Regression cases: each program is built from the listed sources, run with a
# fixed seed, and its stdout+stderr compared byte-for-byte to golden/<name>.out.
#
# name | sources (resolved in regress/fixtures/ first, then the source root) | extra CFLAGS | stdin file | check
#
# check is empty for an exact diff against golden/<name>.out, or "sha256" for
# cases whose output is too large to store: golden/<name>.sha256 then holds the
# digest and line count of the output.
#
# Golden files were generated on macOS/arm64 with Apple clang and libm.  A
# different platform or libm can change low-order digits; regenerate with
# `make golden` and review the diff before committing.
